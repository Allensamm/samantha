# Samantha Bender — independent real estate website concept

16 responsive pages created by Bazalel Design. Static HTML, CSS and JavaScript; no package installation or build server required. Serve the `dist` directory with any static web host. Run `python3 build.py` after changing page copy or property records in the generator; CSS and JavaScript remain in dist. Vercel configuration is included.

## Features

Home, property collection, four property details, buying, selling, communities, about, journal with two articles, contact, privacy and concept notes. Working area/price/style filters, sorting, saved homes in local storage, responsive modal navigation and local enquiry draft/copy/download. Local WebP images and Libre Caslon Text fonts. Reduced-motion handling, semantic HTML, keyboard focus styling and descriptive image text.

## Content and launch requirements

The source Wix portfolio describes a journalism background. Central Ohio was confirmed as the intended market by the user. No current license, brokerage or real estate qualifications were verified. All sample property facts, assigned locations and prices are fictional, and the photos do not represent local inventory. Replace them with approved property information and images before a live business launch. Confirm biography, professional disclosures, portrait and contact destination. Contact currently generates a local draft and sends nothing. No IDX integration, analytics or live valuation is claimed. Pages carry noindex until approved for launch.

See asset-sources.json, dist/assets/FONT-LICENSE.txt and /concept-notes/ for credits and references. Photography downloaded from Unsplash; no stock image represents Samantha.
